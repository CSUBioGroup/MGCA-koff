# Local validation scope

This is a frozen-code release, NOT completed scientific case-study results.

Validated locally:

- Exact frozen model class: forward/backward, finite outputs, initial Drug/Joint
  coefficients 0.30/0.30, and the two AdamW parameter groups (scalar decay zero).
- Actual refit training loop with synthetic 2,773-row data: 33 uninterrupted
  epochs versus interruption after epoch 13 and resume. Model states and
  epoch MSE histories match exactly in this CPU test.
- Completed-run reuse, corrupt prediction-file rejection, old checkpoint-type
  rejection, frozen configuration/epoch/seed checks.
- Reconstruction of the pinned real 2,773-row cohort, followed by repeated
  `PHASE=plan` execution without retraining.
- Both panel plotting paths, both occlusion plotting paths, RDKit SVG output,
  mmCIF/residue/contact mapping, and matplotlib structure rendering, exercised
  on historical data strictly as compatibility fixtures in a temporary directory.
- Shell syntax and Python 3.8 grammar checks.

Not validated by a real run on this workstation:

- CUDA/ESM2 extraction and five full-data refits (weights/GPU unavailable).
- New-model case metrics, new occlusion scores, and scientific conclusions.
- Native PyMOL rendering (optional separate server environment).

No synthetic checkpoints or historical fixture plots are included in this package.
Historical docking geometry is deliberately included and its reuse is disclosed;
all model-dependent scoring and plots are regenerated by the server workflow.
